# Raspberry Pi Router

A home router built from a Raspberry Pi 4, running Raspberry Pi OS Lite.
Handles DHCP, DNS caching, NAT, and firewalling for the local network.

## Hardware
- Raspberry Pi 4 Model B (4GB)
- UGREEN USB 3.0 to Gigabit Ethernet adapter (LAN side)
- Built-in Gigabit Ethernet (WAN side)
- Argon ONE M.2 case

## Status
In progress. LAN interface and DHCP configured. WAN cutover and firewall to come.
